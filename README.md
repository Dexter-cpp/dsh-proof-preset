# 求证 · DSH 本地版

版本 1.1.0-beta.1。适用于 OI 解题、反例定位与有限预算的对拍。

两次相同参数的工具调用连续报告相同文本错误时，下一步会提醒换路。三次后会拦下相同调用。如果继续撞上同一拦截两次，下一个模型步骤会结束本轮。新用户轮次重新计数，其他正常工具操作成功也会解除这段连续失败记录。模型自己发现的 WA、成功退出却没有进展等情况由模式规则处理。

求证 的 `proof_checkpoint` 工具支持 save、read、clear。在同一会话中保存最多 800 字符的断点。继续工作和压缩后会重新提示已保存的断点。切换任务时清除当前断点；原工具调用仍属于 DSH 的会话历史。全新独立会话从空断点开始。

在模式选择器中选 求证，新建会话即可使用。已打开的旧会话可能仍绑定旧版。
